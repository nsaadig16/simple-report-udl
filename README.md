# Quarto Simple Report for UdL

Write a simple report using Quarto!

## Dependencies
To run this, make sure you have **Quarto** and **TinyTex** installed:

### Quarto

Install it directly from their [web page](https://quarto.org/docs/get-started/), following the steps that are provided.

### TinyTex

Once you have Quarto installed, you can run these to install TinyTex:

```bash
quarto check
quarto install tinytex
```

## Installation and usage

To use this template directly on any folder, run the following command:

```bash
quarto use template nsaadig16/simple-report-udl
```
This will create a folder with the report contents inside


Once the project is created, you can then preview it by running `make preview` or render it by running `make render`.
Alternatively, you can directly run the commands listed in the Makefile.
